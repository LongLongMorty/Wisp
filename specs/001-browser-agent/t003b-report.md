# T-003b 协议实现报告

日期：2026-10-18。状态：已完成，静态检查、36项协议行为测试、正式TypeScript类型检查和WXT生产构建全部通过。此任务仅交付协议与校验，不连接真实网页执行器或模型。

## 实现范围

- 页面观察、能力声明、证据、动作结果和逐条件验证。
- 单步模型决定、用量与预算、带来源的提取结果、任务状态与结果、确认请求。
- UI/page角色限定的请求信封、关联原请求的响应、八类事件与订阅回补批次。
- 有界JSON、UTF-8消息限制、UTC时间与有限数字校验、未知字段/分支拒绝。
- 同一TypeScript源码同时导出公开类型及运行时解析器；生成JS与声明，保留Node原生TS行为测试。

实现入口：[packages/protocol/src/index.mts](../../packages/protocol/src/index.mts)。正式结构见[protocol-v01.md](protocol-v01.md)。

## 关键约束

- 页面角色不能发送任务创建、取消或批准消息；角色必须由实际传输sender推导，消息不能自报角色。
- 确认回复只带confirmationId与approve/reject，不接受替换动作参数。
- 响应必须关联requestId/type；订阅事件属于同runId、序号严格递增、eventId不重复，游标不能跳过已返回批次。
- 成功结果必须携带证据或有来源的提取结果；失败/未知状态不被归一化成成功。
- 日志事件不接受原始模型推理或填写值；自由文本中的敏感信息仍需要观察器与策略层过滤。
- 消息大小校验覆盖JSON解码与已解码响应对象；完整观察也受24,000字符限制，不能通过超大元素名/证据数组绕过预算。
