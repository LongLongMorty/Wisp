## 追踪规则

- `FR-*` 为功能需求，`NFR-*` 为质量需求，`AC-*` 为验收场景，`T-*` 为实施任务。
- 需求中的“必须”是 v0.1 验收约束，“建议”是实现选择。
- 契约和计划不能静默放宽 spec；调整范围时同步修改相关验收与任务。
- 任务完成以代码和验收证据为准，本文档中的未勾选项目不代表已经实现。
- 按更新后的任务依赖推进；浏览器环境阻塞时仅先行不依赖浏览器能力的子任务。

## 第一版范围

Chrome MV3 扩展、单标签页执行、DOM 语义观察、CDP 输入、云端或本地服务模型适配、单步闭环、策略确认、任务持久化、执行追踪，以及开发者 SDK 和示例侧边栏。

浏览器内模型推理、多标签页规划、跨域 iframe 操作、视觉定位和通用业务工具注册不在本版验收范围。
