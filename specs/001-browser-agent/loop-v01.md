# T-010 单步循环规格

状态：已完成；实现、工程验证与真实Chrome循环及恢复回归均通过。

运行时通过受信任宿主的 `loop.modelFactory({onAttempt,attemptLimit})` 获得模型。HTTP适配必须将回调传给createChatModel，并将corrections设为attemptLimit-1；脚本提供方每次decide/extract算一次。工厂及schema注册均不接受页面消息。

`configureLoop(runId,{schemas,limits})` 在created时登记schema与运行限制，schema摘要绑定持久化记录；恢复后以同样schema重新配置，不允许重置预算。默认30轮、40次模型调用、5分钟墙钟时长、64000上下文字符、24000观察字符、连续3轮无进展。步数按完整决策轮计数，包含只读/结束候选轮。上下文计数表示本轮输入大小，不把字符当token。

`step` 每次重新观察，只提出一个决定；action ID由运行时生成，执行只能经过原execute与策略网关。`drive` 串行调用step，遇到paused/waiting_user/终态停止；同一run只允许一个循环操作。恢复不自动运行，不重用旧决定或观察。

模型输出即使来自自定义提供方也重新解析。动作白名单、目标作用域、schema注册和输出大小由宿主校验。finish须真实verify所有非空expected并有证据，失败不完成；extract先校验数据与来源，再重读观察确认未变化、验证当前URL，才能完成提取任务。提取来源只证明输入观察，不证明复杂业务事实。

每次模型操作先以事务预留最多2个调用额度，onAttempt同步消耗预留，超过额度拒绝；剩余额度只有1时只允许一次请求。正常返回/失败后返还未用额度；Worker中断时保守保留全部预留，防止重启超用。自定义工厂必须在每次网络尝试前调用onAttempt，否则不能保证它内部的重试记账。提供方忽略取消时，运行时通过竞速停止等待并拒绝迟到结果。

预算、轮数、耗时、元数据历史摘要与最近观察语义摘要持久化。历史最多16项固定元数据，不记录填写值、原观察、原始模型内容、提取数据或推理；最终用户请求结果按既有任务结果规则保留。无进展比较URL、文档、文本、元素语义和滚动位置，排除observationId/捕获时间；此启发式不声称理解业务进展。

循环使用同一运行时代次与AbortSignal。每个异步边界后检查租约/状态/代次；暂停、取消、干预、租约丢失或总超时均阻止新动作及完成提交。确认挂起后停止模型；批准由既有confirm负责，宿主可显式再次drive。ask_user进入waiting_user，继续须先暂停并显式恢复；不接受模型授予权限。

验证：确定性测试覆盖搜索动作→证据完成、结构化提取、非法模型输出/来源/目标、失败完成候选、各预算、无进展、格式纠正额度、跨恢复记账、确认/未知动作阻断、暂停取消与迟到结果。真实Chrome集成以脚本模型连接真实策略网关，单独验收，不将内存替身标为浏览器通过。
