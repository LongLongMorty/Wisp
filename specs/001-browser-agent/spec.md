# 需求规格

## 产品目标

Wisp 让开发者能够在用户浏览器内运行网页 Agent，并独立复用不依赖模型的页面控制层。用户通过示例侧边栏发起任务，观察执行过程，并随时停止或接管。

本版“端侧”指观察、控制、策略和状态管理运行于浏览器扩展。模型可以部署在云端或本机服务；调用云端模型时，经过过滤的页面信息会发送到所选提供方，不承诺数据完全不离开设备。

## 用户场景

| 编号 | 用户 | 场景 | 可观察结果 |
| --- | --- | --- | --- |
| US-01 | 开发者 | 不接入模型，直接观察和操作页面 | 得到目标引用、动作状态和验证证据 |
| US-02 | 最终用户 | 搜索记录并进入详情 | Agent 单步推进，返回有依据的结果 |
| US-03 | 最终用户 | 筛选表格并提取指定字段 | 返回符合 schema 的数据及来源 |
| US-04 | 最终用户 | 填写表单，在提交前确认 | 填写完成，提交动作挂起并展示具体内容 |
| US-05 | 最终用户 | 中途停止或浏览器运行时中断 | 不继续发起动作；恢复时重新观察 |

## 范围与非目标

本版仅操作用户明确选择并授权的一个普通 HTTP(S) 标签页，同一任务可在已授权 origin 内导航。新 origin 必须先获得授权。

不支持：浏览器内部页面、隐身模式、文件上传下载、支付、密码或验证码输入、授权授予、多标签页任务、跨域 iframe 操作、Canvas 内部定位、closed Shadow DOM、自动解验证码、后台定时任务。遇到不支持的操作返回明确原因并请求接管，不猜测成功。

## 功能需求

| 编号 | 必须提供的行为 | 验收 |
| --- | --- | --- |
| FR-001 | 导出独立 BrowserAdapter 与 Agent SDK；控制层不依赖模型、UI或模型密钥 | AC-01 |
| FR-002 | 观察当前文档 URL、标题、视口、可见交互元素和有界文本；元素包含角色、名称、状态、边界和作用域引用 | AC-01、AC-03 |
| FR-003 | 提供 click、fill、pressKey、scroll、navigate；执行前检查文档、目标身份、可见性、启用状态和遮挡 | AC-01、AC-04 |
| FR-004 | 失效引用必须拒绝；禁止将旧引用自动重绑定到语义相似元素；普通无关 DOM 变更不强制废弃所有有效引用 | AC-04 |
| FR-005 | 模型一次最多提出一个动作或终止决定；输出必须通过 schema 校验；页面内容按不可信数据处理 | AC-02、AC-10 |
| FR-006 | 动作结果分别描述派发、页面响应和后置条件；不得以 DOM 变化代替业务成功 | AC-02、AC-05 |
| FR-007 | 支持读取结构化数据并校验 schema，携带 URL、观察 ID 等来源；不符合 schema 不得作为成功结果 | AC-03 |
| FR-008 | 执行前运行本地策略；提交、发送、删除等已识别写入动作默认确认；密码、验证码、支付和授予权限转人工；未知语义动作默认确认 | AC-06、AC-10 |
| FR-009 | 确认展示站点、目标、动作和可展示参数；批准绑定动作及页面状态，拒绝或状态失效后不得执行；不提供全局自动批准模式 | AC-06 |
| FR-010 | 支持取消、暂停、恢复和用户接管；取消阻止后续动作与迟到模型结果；已派发动作不能承诺撤销 | AC-07 |
| FR-011 | 持久化任务检查点和动作日志；重启后进入暂停状态；结果未知的动作先核对结果，禁止直接重发 | AC-08 |
| FR-012 | 每标签页仅一个写入执行者；执行前检查租约，UI重复请求不重复执行；检测到用户干预时暂停或重新观察 | AC-07、AC-09 |
| FR-013 | 支持可替换模型提供方，至少验证一个实际端点；模型调用支持取消、超时、结构化响应和用量记录 | AC-02、AC-11 |
| FR-014 | 提供示例侧边栏：选择当前标签页、发起任务、展示进度与证据、确认、暂停、恢复、停止 | AC-06、AC-07 |
| FR-015 | 提供步数、总时长、模型调用次数、上下文大小及重复无进展上限，超限停止并报告原因 | AC-11 |
| FR-016 | 权限按 origin 授予；阻止未授权导航及越界操作；不支持的 frame/页面返回能力错误 | AC-10 |
| FR-017 | 提供有界证据验证：URL、元素出现/消失、文本包含、字段值；业务完成必须有证据或明确标为未验证 | AC-05 |

## 质量需求

| 编号 | 约束 |
| --- | --- |
| NFR-001 | 模型输出不能执行任意 JavaScript；只允许契约定义的动作和参数 |
| NFR-002 | 密码值不进入观察、模型请求和日志；识别出的敏感字段默认排除；不承诺识别任意自由文本中的全部个人信息 |
| NFR-003 | 密钥只在扩展受信任上下文中使用，不发给目标页、不写入 trace；页面消息不能修改授权或确认结果 |
| NFR-004 | 记录 runId、stepId、actionId、耗时、状态、证据、模型调用与可用用量；默认不保存全量 DOM 和截图 |
| NFR-005 | 本地固定验收集的确定性控制与策略场景全部通过；模型端到端三个正常场景各运行五次，至少各四次完成，且不得出现未授权写入 |
| NFR-006 | 稳定本地测试页面中，200个可见候选元素的观察耗时 p95 ≤ 500ms，连续采样30次；记录机器、Chrome版本和测量边界，不含模型与页面等待 |
| NFR-007 | 用户停止后不再发起新动作；本地状态和界面在1秒内反映停止，外部已发请求尽力中止 |

## 默认预算

最多30个动作步骤、5分钟任务时长、40次模型调用、连续3次无进展后暂停；观察序列化文本最多24,000字符，完整模型请求最多64,000字符。保留当前观察和历史摘要，截断须显示截断标志，不允许静默丢失用户目标。适配器可增加 token 预算，但不得声称字符数等于 token 数。

费用可在提供方支持时估算并设置上限；无计价数据时明确显示未知，不能宣称精确费用限制已生效。
