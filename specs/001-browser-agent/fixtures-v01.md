# T-004 本地验收站点规格

目标：为AC-01–12提供本地、可重置、相互隔离的业务页面和独立事实来源。此任务只建立测试环境，不实现Agent、浏览器适配器或模型。

## 服务边界

使用Node内置HTTP服务，不增加第三方依赖。默认仅监听127.0.0.1，动态分配三个端口：应用站点、跨origin frame站点、测试控制站点。每次测试通过控制站点创建独立session；所有业务URL包含sessionId。控制API的随机Bearer token只返回测试进程/启动终端，不注入HTML、脚本或应用API，且不开放CORS。

控制API提供创建、重置、销毁、配置延迟结果及读取业务事实。重置增加session generation，并清空提交/保存/点击等副作用；重置前仍在等待的请求不得修改新generation的业务状态。不同session互不影响。应用只访问正常业务API，不读取测试oracle或Agent私有标识。

## 页面目录

| 页面 | 内容 | 对应验收 |
| --- | --- | --- |
| /search、/records/:id | 固定工单搜索与详情导航，存在同名项以区分准确命中 | AC-02 |
| /table | 按状态/优先级筛选，固定数据至少包含五条待处理高优先级记录 | AC-03 |
| /form | label关联的标题、描述、优先级与提交按钮，服务端累计真实提交次数 | AC-06–09 |
| /controls | 原生label输入、禁用按钮、遮挡层、open Shadow DOM、长页面滚动 | AC-01 |
| /rerender | 无关计数器更新与同名按钮节点替换；普通click上报真实副作用 | AC-04 |
| /delayed-save | 加载提示先出现，保存延迟成功或失败；后台无关DOM更新不代表保存成功 | AC-05/07/08 |
| /safety | 明确的测试注入文本、password/验证码/令牌字段、未授权origin链接和跨origin iframe | AC-10 |
| /performance | 恰好200个可见交互候选按钮；独立响应计数器 | AC-12 |

站点首页给出普通导航及测试任务示例，不暴露答案数组或控制token。实际页面路径为/s/<sessionId>/<page>。iframe站点使用不同端口，构成不同origin，不依赖外部网站。

## 独立事实与断言

测试进程通过控制API读取提交记录、保存记录与操作计数，使用Node assert核对；搜索/表格的期望记录由独立oracle导出，不能由Agent结果反推。需要同时支持检查未执行、执行一次、重复执行和重置清空。事实端点不接受Agent提供的success标志作为成功依据。

## 本任务完成条件

- 固定数据、场景路由和本地静态资源可提供；无CDN/真实第三方账户。
- HTTP集成测试覆盖隔离、控制API权限、搜索/筛选/详情、真实副作用计数、保存成功/失败、重置与进行中请求竞态、输入边界和资源路径。
- 静态检查、原有协议测试、类型检查及扩展生产构建保持通过。
- 尝试真实Chrome页面smoke，分别记录成功、失败或环境阻塞；完整Agent动作与AC整体验收仍由T-005之后验证，不用本任务测试替代。
- 结果绑定源码hash、fixture版本、环境和命令；保留失败记录。
