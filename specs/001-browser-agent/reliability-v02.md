# T-014 实测问题修复规格

状态：实现和确定性回归已交付，待真实Chrome及同一模型15轮复验。保持原15轮/各类≥4次、零未授权副作用、性能与人工门槛，不更换模型规避问题。

1. 观察增加普通input/textarea的脱敏有界value（2048字符、截断标识），单选select增加当前value及最多50个选项的value/label/selected/disabled；敏感字段、扫描不完整时不暴露值或选项。仍服从24,000字符/字节预算。标签命名不把select选项全部拼进名称。
2. 新动作selectOption只支持原生单选select，按精确option.value定位，拒绝缺失/重复/禁用选项、多选、自定义组件、旧引用及敏感目标。通过隔离世界固定代码调用原生setter、派发input/change，再验证实际选中值；事件isTrusted=false，不宣称等价真实用户输入。策略仍默认确认，仅明确fixture筛选规则允许，授权/敏感/去重/unknown屏障不可绕过。
3. 宿主可传completionConditions（最多16个url/text/element条件，拒绝易失value引用），持久化且首次配置后不可降低，resume省略时沿用。URL条件支持互斥的equals或startsWith。finish验证宿主条件与模型条件的并集，模型不能通过少报条件获得completed；提取完成也必须满足宿主条件。模型输入显式携带条件，提示展示URL+文本与全部合法按键/selectOption契约。搜索仅传详情路由前缀与任务已有标题，不把oracle记录ID或确切详情URL泄露给模型。
4. 历史只记录动作kind、目标ref、派发/验证/错误码等元数据，不保存字段值；当前普通字段值来自新观察，支持判断哪些字段尚未填写。语义指纹纳入字段值/选中状态，使实际填写和筛选变化能被识别。记录失败stopReason/错误码，避免所有失败只显示STARTING。
5. 更新SDK、面板RPC、协议与类型，新增确定性测试和真实Chrome探针，固定搜索宿主URL+文本条件、table使用selectOption。新任务/提示版本归档旧证据后重跑，不手改历史成绩。真实模型未配置/浏览器阻塞及人工未做时保持未完成。

这不是把fixture真值输入模型：宿主搜索条件来自已声明任务配置，表格真值仍仅用于独立断言，普通页面观察不包含oracle控制凭据。自定义下拉框仍需已有动作或接管，付款/密码/验证码策略不放宽。
