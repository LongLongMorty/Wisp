# 支持范围与已知限制

本版验证限定于本地可重置fixture；不是对任意网站可靠性的声明。需求与证据见[追踪表](../specs/001-browser-agent/traceability.md)。

| 项目 | 支持与边界 |
| --- | --- |
| 宿主/浏览器 | Chrome MV3原生侧边栏；声明最低125，实测156.0.8078.35；Chrome 125、Edge、Firefox、Safari及其他系统未形成同等验收证据 |
| 操作范围 | 用户明确选择并授权的单个普通HTTP(S)tab；仅在已授权origin内导航，新origin需另授权 |
| 页面观察 | URL、标题、可见交互元素、有界文本、普通字段脱敏值；元素值/选项与整体观察均可截断 |
| 控制动作 | click、fill、pressKey、scroll、navigate、selectOption；执行前检查引用、可见/启用、遮挡及授权 |
| 输入 | 普通input/textarea；open Shadow DOM；fixture的React 18.3.1受控输入/原生受控select通过。contenteditable写入及其他框架/富文本不承诺支持 |
| 下拉选择 | 原生单选select，精确且唯一的option.value，拒绝禁用项；程序setter与input/change后验证，不是物理点击。多选、自定义组件不提供selectOption保障 |
| 引用 | 节点身份与文档/观察作用域绑定；移除/替换或过期拒绝，旧引用不重绑同名元素 |
| 结构化提取 | 有界JSON Schema子集、来源绑定、独立验证；不是完整JSON Schema实现 |
| 完成判定 | 宿主completionConditions与模型条件并集；URL/文本/元素/字段等有界证据；无法证明业务效果就不声称成功 |
| 确认/恢复 | 未知或写入默认确认，令牌一次使用；Worker/面板中断后暂停、预算保留、unknown先核对，不直接重发 |
| 模型 | 可配置兼容Chat Completions端点或本机服务；已有DeepSeek实际15轮通过。不同提供方、模型版本、站点与提示变化需要复验 |

不支持浏览器内部页面、隐身模式、跨域iframe操作、Canvas内部定位、closed Shadow DOM、文件上传/下载、支付、密码/验证码输入、自动解验证码、授权授予、多标签页任务和后台定时任务。实际操作返回能力错误、拒绝或请求接管；不承诺每种不支持页面都能自动生成完整接管说明。

默认限制：30步、5分钟、40次模型调用、连续3次无进展后暂停；观察序列化最多24,000字符，完整模型请求最多64,000字符，另有载荷/字节限制。一次格式纠正可能增加一次真实HTTP尝试，仍计入预算。字符数不是token数；提供方不返回费用时费用未知。

Q-001的最低版本回归、Q-003的更多框架和控件、Q-004的更多模型端点/CORS差异、Q-005物理用户输入归因仍有边界。特别是未知输入信号需由可信宿主通知/显式接管处理，不保证自动准确识别每一次人工干预。关键词如“登录”可能触发保守接管，即使目标是普通工单标题。

实际15轮由受信任Node宿主、内存store、真实模型HTTP、运行时/策略与Chrome/CDP组成，不是15轮生产侧边栏模型任务。原生侧边栏/Worker与IndexedDB另有真实故障回归和人工检查。当前归档样本为search/table/form各5/5、零未授权副作用，不能外推为概率为100%或通用网页成功率。

没有执行Chrome商店发布、npm公开发布、自动部署或广泛网站兼容测试。请先在可重置场景验证自己的站点规则与数据范围。
