# 0.1.0-rc.1

本地源码与Chrome MV3扩展候选，尚未公开发布。内部工作区包版本仍为0.1.0。

- 单标签页观察、六类控制动作、授权/一次性确认、可恢复任务运行时和SDK句柄。
- 原生侧边栏与可配置模型端点；普通字段状态、原生select选择及宿主完成条件验证。
- 限定fixture上的实际模型15轮、故障137项、可靠性15项、性能与人工检查已有通过证据；状态行指纹差异通过独立冻结复核处理。
- 安装、SDK、权限数据流、支持范围和41条需求追踪文档。

限制见[支持范围](support.md)。最低声明Chrome125未做同等回归；Q-005物理用户输入来源归因仍保留；自定义下拉、多选、跨frame等超出当前支持范围。fixture成绩不代表任意真实网站成功率。

源码包不含依赖、缓存、密钥、浏览器profile或历史证据归档。首次安装可能需要网络。解压后按[安装说明](getting-started.md)构建；扩展ZIP解压后在Chrome开发者模式加载根目录。没有执行Chrome商店发布或新的人工加载验收。
